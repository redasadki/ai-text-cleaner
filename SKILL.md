# AI Text Cleaner

Sanitize and reformat Markdown text generated by LLMs (ChatGPT, Claude, Gemini, Perplexity, etc.). Fixes the mechanical problems that copy-pasting from AI chatbots creates.

## When to use

- Cleaning up AI-generated Markdown before publishing or editing.
- Fixing encoding artifacts (mojibake) from copy-paste between systems.
- Repairing broken Markdown tables from AI output.
- Removing AI citation brackets, artifact labels, and meta-text.
- Removing Perplexity-specific links (file uploads, search links, and trailing end-of-line source citations) while preserving all legitimate Markdown links.
- Standardizing formatting (bullets, headers, quotes, dashes).
- Preprocessing text before applying editorial style rules.

## What it fixes

1. **Encoding artifacts** -- `â€™` → `'`, `Ã©` → `é`, and other UTF-8 mojibake.
2. **Broken tables** -- Merges split rows, detects true column count, strips ghost columns.
3. **AI cruft** -- Removes `[cite_start]`, `[1][2]`, `Artifact 1:`, `Screen 2:` labels.
4. **Perplexity footnotes** -- Strips `[^1]`, `[^1][^2][^3]` inline footnote references.
5. **Perplexity-domain links** -- Removes `[text](url)` where the URL is on `perplexity.ai` or a `ppl-ai-*` S3 bucket.
6. **Trailing end-of-line citation links** -- Removes any `[label](url)` that Perplexity appends as the last token after prose text or a list item's text content, regardless of domain. Standalone reference items and annotated bibliography entries are protected.
7. **Split structures** -- Merges headers and list items broken across multiple lines.
8. **Formatting** -- Standardizes bullets to `-`, converts bold-only lines to `##` headers, removes trailing colons from headers, fixes quote marks and dashes.
9. **Dense paragraphs** -- Splits run-on text blocks at sentence boundaries.

## Link removal rules

Applied in order:

1. If the URL is a Perplexity domain (`perplexity.ai`, `ppl-ai-*`) -- always remove.
2. If the line content (after stripping a list prefix) is solely the link -- always keep (standalone reference).
3. If the link is immediately followed by ` - description` text -- always keep (annotated bibliography).
4. If the link is the last token on the line and prose precedes it -- remove (trailing citation).
5. Otherwise -- keep.

## Usage

```bash
# Clean a file
python3 scripts/clean_ai.py input.md > output.md

# Clean from clipboard (macOS)
pbpaste | python3 scripts/clean_ai.py | pbcopy

# Pipe from stdin
cat input.md | python3 scripts/clean_ai.py > output.md
```
